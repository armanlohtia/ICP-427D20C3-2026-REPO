# Week 1 — DevOps Foundations

## Overview
Week 1 focused on Linux command-line fundamentals, application log analysis, Bash scripting, troubleshooting, and Git version control.

## Practical work
- Navigated directories and inspected files using `pwd`, `cd`, `ls`, `head`, and `tail`.
- Created and managed files using `mkdir`, `touch`, `cat`, `cp`, and `mv`.
- Searched files and text using `find` and `grep`.
- Analysed logs using `wc`, `awk`, `sort`, and pipelines.
- Practised output redirection, file permissions, and process inspection.
- Wrote and tested a Bash configuration health-check script.
- Practised Git history inspection, branches, merge conflicts, `git restore`, and `git revert`.

## Evidence
- `evidence/linux/application.log` — sample application log used for investigation.
- `evidence/linux/errors.log` — error entries filtered from the sample log.
- `evidence/linux/incident-report.txt` — investigation summary.
- `linux-git-practice.md` — command examples and explanations.
- `health-check.sh` — configuration validation script.
- `project-selection.md` — proposed internship project roadmap.

## Key learning
Linux tools help investigate system behaviour, shell scripts automate repeatable checks, and Git provides a controlled way to track and recover changes.
